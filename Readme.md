# Voca100ReColor

ニコニコ動画・YouTube・Kiite・VocaDB のリストのサムネイルを **色順に並べて、1枚のPNG画像にする** Webアプリです。
「ボカロ100選」のような画像を、見栄えよく(色のグラデーションで)作ることを目的にしています。

- 画面(HTML)は静的ファイルなので GitHub Pages で公開できます
- ニコニコやYouTubeへの通信は、Cloudflare Workers の小さなAPIが中継します
- 色の解析と画像の合成は、すべてブラウザ内で行います

## 特長

- リストのURLを貼るだけで、サムネを色の近い順に並べて画像化
- 並び順は「色相順(虹のグラデーション)」「明るい順」「並べ替えなし」から選べる
- 列数・行数、セルの形(16:9 / 4:3 / 正方形)、セル幅、すき間、背景色を調整可能
- スネーク配置(偶数行を逆順にして、行をまたいでも色がつながる並び)
- 設定を変えるたびに、再読み込みなしで画像が組み替わる
- PNGとして保存可能

## 対応しているリスト

| サービス | URLの例 | 備考 |
| --- | --- | --- |
| ニコニコ動画 マイリスト | `https://www.nicovideo.jp/user/123456/mylist/12345678` | |
| ニコニコ動画 シリーズ | `https://www.nicovideo.jp/user/123456/series/12345` | |
| YouTube | `https://www.youtube.com/playlist?list=PLxxxxxxxx` | 公開または限定公開のリストのみ。APIキーが必要 |
| Kiite | `https://kiite.jp/playlist/xxxxxxxxxx` | 1リスト100曲まで(Kiite側の上限) |
| VocaDB | `https://vocadb.net/L/12345` | 公式(Original)PVのサムネがある曲のみ |

1リストにつき最大1,000件まで取得できます。

### 取得できない動画について

- YouTube: 非公開・削除済みの動画は除外されます。ミックス(`list=RD…`)、「後で見る」などの自動生成リストは取得できません。
- VocaDB: PVのあるサービスは、YouTube → ニコニコ → SoundCloud → Bandcamp → Vimeo の順に優先します。

## 使い方

1. 公開されているページを開く
2. 「リストのURL」にURLを貼り、列数・行数(初期値は10×10)を決めて「サムネを読み込む」を押す
3. 並び順やセルの形などを調整する(再読み込みは不要)
4. 「PNGを保存」で画像をダウンロードする

列数や行数を、読み込んだ件数より増やしたときは、もう一度「サムネを読み込む」を押してください。

## 仕組み

```
ブラウザ (index.html)  ──→  Cloudflare Worker (src/index.ts)  ──→  ニコニコ / YouTube / Kiite / VocaDB
  色の解析・並べ替え・画像の合成        リストの取得・サムネの中継(CORS付き)
```

ブラウザだけでは、他サイトのデータを読む制限(CORS)と、他サイトの画像を描き込んだ canvas を書き出せない制限があります。
そのため、リストの取得とサムネの中継だけを Worker に任せています。

### 色の並べ替えのアルゴリズム

1. サムネを 64×36 に縮小する(ノイズと圧縮劣化の影響を抑える)
2. 各画素を HSV に変換する
3. 彩度が極めて低い画素・ほぼ黒の画素を無彩色として別集計する(パステルカラーは有彩色として残す)
4. 有彩色の画素を、色相の10度刻み(36区間)のヒストグラムに集計する。票の重みは「面積 × 彩度 × 明度」
5. 円環上で近い色相の区間を統合する(359度と1度は隣として扱う)
6. 各グループのスコアを「重み付き画素数 × 色相のまとまり」で計算する
7. 最もスコアの高いグループをメインカラーにし、代表色のRGB値を求める
8. 有彩色が優勢でない画像(モノクロ・低彩度など)は、無彩色として扱う

並べ替えでは、有彩色を色相の昇順に並べ、無彩色は明るい順にして末尾に置きます。

## 制限と注意事項

- **無料プランの上限:** Cloudflare Workers の無料プランは、1日10万リクエストまでです。100枚の画像を作るたびに約100リクエストを使うため、**1日1,000回程度**が目安です。公開して利用が増えると上限に達することがあります。
- **非公式APIの利用:** ニコニコ動画・Kiite は、公式に公開されていないAPIを利用しています。仕様変更により、予告なく動かなくなる可能性があります。
- **YouTube APIの利用枠:** YouTube Data API には1日あたりの利用上限があります。読み込めない場合は、日を改めてお試しください。
- **サムネイルの権利:** サムネイルの著作権は、各動画の投稿者・権利者にあります。生成した画像を公開・配布する際は、各サービスの利用規約や権利にご配慮ください。
- 非公開のリスト、削除された動画は取得できません。
